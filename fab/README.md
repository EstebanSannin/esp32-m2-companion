## Order settings — confirmed against JLCPCB quote UI 2026-08-30 (v1), unchanged for rev B
- **Layers 4**, thickness **0.8 mm**
- **Specify Stackup: Yes → JLC04081H-3313** (Standard, 0.80 mm, prepreg 3313
  RC57% 0.0994 mm). This alone locks the geometry that sets the USB impedance.
- **Impedance Control: No requirement** (i.e. OFF). Deliberate: JLC charges
  ~€28 for it, and the ESP32-S3 USB is Full-Speed (12 Mbps) only — controlled
  impedance is functionally irrelevant. The stackup spec above already pins the
  0.0994 mm prepreg, and the verified 0.14 mm traces give ~88 Ω regardless
  (see docs/stackup.md). The paid option only buys a TDR measurement, not a
  different board.
- Surface finish **ENIG**.
- **Gold Fingers: Yes** (hard gold on the M.2 edge contacts).
- **Beveling: No** — forced. JLC UI: *"Beveled fingers cannot be produced for
  PCBs smaller than 50mm x 50mm."* Our card is 22×42. **Consequence:** square
  90° finger edge. Before first insertion, lightly **hand-chamfer the leading
  edge** (~45°, ~0.2–0.3 mm, both faces, leading corner only — do not sand the
  contact tips) so it seats without stressing the host M.2 socket.
- **Castellated holes: No** — rev B. The M.2 mounting notch is now **part of
  the board outline** (routed with it): no drill hit, no plating, no copper.
  v1 had it as a plated hole on the edge → JLC flagged castellation,
  $38 setup fee. Rev B has no plated feature on any board edge, so if JLC's
  DFM flags castellation, something is wrong — stop and check, don't pay.
- Confirm Production File: **Yes**; Deburring/Edge rounding: Yes; Mark: Remove.
- **Assembly: both sides**, 5 pcs
- 7 Extended parts (feeder fee ~$3 each): U2 module, U1 USBLC6 (ST C7519),
  D1/D2 BAT54A, D3/D4 side-view LEDs, J3/J4 JST SH
- DNP (not placed): R5, R6, C8, C9 — excluded from BOM + CPL by the netlist,
  crossed out on the assembly drawing (docs/review/rev_b_drawings.pdf)

## Order steps (rev B — after the v1 LED reversal)
1. `make fab` → upload the 3 files above.
2. In the **assembly placement preview**, open `fab/polarity_checklist.md`.
3. For **every row** (D1–D4, U1, U2, J3, J4) check the preview against the
   row, using N/S (screw-notch edge / gold fingers) — the bottom-side preview
   is mirrored, so E/W is not reliable. **LEDs: the "+" must be on the pad
   level with the series resistor (R3/R4), i.e. the N pad.**
   **Never approve a preview by eye.** If a part is rotated, fix `JLC_ROT`
   (not the footprint) and regenerate.
4. Set the verified date for each `JLC_ROT` entry, re-run `make fab` (must
   exit 0), re-upload the CPL, re-check the preview once more, then order.

Do not order before GATE B3 (owner). See docs/review-findings.md.
